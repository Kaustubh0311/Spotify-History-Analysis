🎧 Spotify Listening History Dashboard
Turning listening history into meaningful music insights.

📌 About the Project
The Spotify Listening History Dashboard is an interactive Power BI project designed to explore personal music-listening behaviour through historical streaming data.

It transforms listening records into meaningful visual insights, helping understand listening habits, favourite artists, popular tracks, monthly trends, and skipped songs.
✨ Dashboard Highlights
- Total Streams and Listening Hours
- Average Listening Time
- Unique Artists and Tracks
- Skip Rate Analysis
- Monthly Listening Trends
- Top Artists and Most Played Tracks
- Listening Completion Status
- Weekday and Time-Period Analysis


🛠️ Tools & Technologies
Power BI
Power Query
DAX
Data Visualization
Data Cleaning
Data Analytics

💡 Key Learnings
- Understanding user listening behaviour through data.
- Creating meaningful KPIs and DAX measures.
- Designing interactive analytical dashboards.
- Identifying listening trends and patterns.
- Transforming raw historical data into visual insights.
  
🎯 Project Objective
To transform Spotify listening history into an interactive analytical experience that reveals music preferences, listening patterns, and streaming behaviour through data visualization.
